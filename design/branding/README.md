# Quervio branding

Reference from the Quervio branding package, kept after its integration.

- `design-tokens.json`: the dark palette and type roles. The values in use live in `src/lib/themes.ts` (theme "Quervio Dark").
- `SOURCES.json`: where each asset came from, with its SHA-256. Its paths are those of the original package: the files are now in `src/assets/` (Q Prisma v2 PNGs), `src/assets/fonts/` (Inter, JetBrains Mono and their licences) and `src-tauri/icons/source.png` (the transparent PNG, source of the native icons).
